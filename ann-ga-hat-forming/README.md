# ANN–GA 기반 Hat 형상 성형공정 최적 설계

**구분:** AI응용제조 개인 설계 과제 (2026)

## 연구 문제

목표한 성형 후 Hat 단면 형상에 가깝도록 금형의 설계변수를 역으로 결정합니다. 일반적인 계산은 금형 → 성형 후 제품의 순방향 해석이지만, 본 과제에서는 ANN 대리모델을 만들고 GA로 금형 후보를 탐색했습니다.

## 수행 흐름

1. 수업 제공 `input.csv`와 `target.csv`의 **891개** Abaqus 기반 성형 데이터를 읽어 입력/출력, 결측 및 ID 정합성 검토
2. 입력 **5개** → 출력 **7개** ANN 모델을 만들고 Train/Validation/Test 분리 후 정규화·하이퍼파라미터 탐색
3. 독립 Test 134개에서 예측 오차를 분석하고 반경 예측의 상대적 약점 확인
4. 금형 형상을 정의하는 **4개의 독립변수**를 유전알고리즘으로 탐색
5. 목적함수 가중치를 변화시켜 높이·각도·스프링백 오차의 상충관계 비교

## 확인된 주요 결과

- 총 891개 사례, Train 623 / Validation 134 / Test 134
- Test R²: `H 0.9970`, `L1 0.9890`, `L2 0.9764`, `R1 0.7717`, `R2 0.6393`
- 기준 가중치 설계안 스프링백 ANN 예측 `0.5379°`; 스프링백 우선 대안 `0.1041°`
- 스프링백 우선 대안에서는 높이 절대오차가 `0.9302 mm → 0.9453 mm`로 소폭 악화

## 개인 기여와 검증의 범위

기계공학 과제의 모델 설정, ANN·GA를 이용한 비교, 수치 결과 검토 및 발표 자료 정리에 참여했습니다. **Colab 코드 구성에는 생성형 AI 도움을 받았으며**, 코드를 처음부터 전부 독자 작성했다고 주장하지 않습니다. 원본 891개 사례는 **제공된 Abaqus 기반 학습 데이터**이며 직접 891건의 Abaqus 해석을 수행한 것이 아닙니다.

> **주의:** GA의 최적 설계는 ANN 예측 결과입니다. 새로운 Abaqus FEA, 실제 시편 제작, 성형 불량 및 금형 간섭 검증은 이루어지지 않았습니다. Notebook의 저장 출력은 참고 자료이며, 완전 재실행에는 수업 제공 CSV 및 실행 환경의 준비가 필요합니다.
